# IS373 RAG Research

Plan for a small access guide with traceable answers. Run the isolated keyword check with `python check_baseline.py` from this directory.

The VitePress site organizes the plan into technical research, retrieval comparison, architecture, sources, and evaluation. Its pages are generated from `research.md`, which also supplies the baseline fixtures.

Run `npm ci` and `npm run dev` to preview locally. Run `npm run build` to check the production build. The included workflow publishes from `main` after GitHub Pages is configured to use GitHub Actions.
